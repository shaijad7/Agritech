# AgriTech

AgriTech is a web-based platform designed to bring different farming-related activities together in one place. The system provides features for farmer support, labour management, crop guidance, disease detection, and role-based access.

## Features

- Farmer management
- Labour management
- Crop guidance
- AI-based crop disease detection
- Role-based access
- JWT authentication
- Centralized dashboard
- User-friendly web interface

## Tech Stack

- Next.js
- JavaScript / TypeScript
- Node.js
- MongoDB
- Firebase
- JWT Authentication
- AI / Machine Learning

## Project Overview

The main goal of AgriTech is to provide a single platform where users can access and manage different farming-related services.

The application includes separate functionality for different types of users and provides role-based access to protect application features and data.
